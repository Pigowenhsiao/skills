Workflow:

1. Generate the key images first
Create wide 16:9 stage battle shots from a front-row audience POV.
This is where most of the visual style gets established:
smoke, explosions, destruction, lighting, energy effects, crowd atmosphere, overall intensity.

2. Turn the images into video in Flova
Use each image as the starting frame.
A typical motion sequence looks like:
character movement → ultimate move charge-up → attack clash → stage destruction → camera shake → crowd reaction.

3. Edit everything together
Focus mainly on timing, sequencing, and transitions.
Since most of the visuals are already built into the images, editing stays fairly simple.

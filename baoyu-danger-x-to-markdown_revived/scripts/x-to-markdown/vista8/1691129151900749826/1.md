想背单词？百词斩、流利说、墨墨背单词、Anki、不背单词，各种App换来换去也没记住多少。

最后发现，还是读英文故事学单词最有效。

曾尝试提供一个单词，AI解释词根词缀，拓展形似词、近义词，然后用这些词再不同难度的英文短篇故事学习，但实际生成的故事情节非常拉胯，毫无记忆点。

直到有天看Youtube，发现两个英语百字短文网站。（前些天分享过）

https://t.co/9WWwah4FkY
https://t.co/1YXBoYGtHL

开启每天读英文故事学单词，做法如下：

1. 每天找以上网站找一篇英文短文，复制到任意笔记本工具。比如Obsidian、iOS备忘录等。

2. 先硬着头皮读一遍，加粗标记不认识、看不懂的单词、词组或短语。

3. 然后用GPT4 interpreter或https://t.co/vG8rNXdNhg 翻译成中文，再对照读一遍。（参考Glasp插件用法）

4. 把翻译结果粘贴到笔记中，做成英文故事双语翻译版。

5. 再把加粗的单词复制粘贴丢给AI，让它生成释义、发音和使用场景说明。

Prompt如下：

“你是一名多年教学经验的优秀中英双语老师，你擅长解释单词/词组的释义、音标，并给出使用场景案例，帮助学生快速学习记忆。如有上下文，优先用文中的单词释义。

输出格式：
<单词/词组> [<音标>] ，<中文释义>
场景：<场景案例>

在处理前，询问我是否有需要指定处理的单词或词组。如果我回复no，这是再从文章中提炼最值得学习掌握的单词和词组，然后处理。”

最后一步，整理学习笔记发到Twitter（X）打卡，靠社交关联，提升学习意愿。

理论上这肯定不是最佳学单词方法，依赖翻译，也没摆脱中文思维习惯，但是胜在操作简单，有收获感，有利于养成习惯，感兴趣的朋友，可以和我一起无脑坚持一个月看看。

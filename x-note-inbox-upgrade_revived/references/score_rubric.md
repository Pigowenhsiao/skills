# x-note2 評分對照表（0-50 分制，繁體中文）

## 分數標準（0-50 分）

| 分數 | 等級 | 標準 | 繁中關鍵線索 |
|------|------|------|-------------|
| **45-50** | 極高價值 | 完整提示詞+工作流+可重用模式；高密度原創技術；提出新概念並附檢驗標準；實戰避坑含具體金額/數據 | 原創概念、策略深度、實戰避坑、極高價值、附具體數據 |
| **40-44** | 高價值 | 可重用提示詞（附完整規格）；或多步驟工作流+具體工具+可驗證輸出；明確的開源/團隊計畫 | 可複製框架、具體構想、實用性高、有數據支撐 |
| **35-39** | 中高價值 | 具實質內容的工作流/洞察；清晰洞察+合理互動 | 工作流、洞察、實用內容、有參考價值 |
| **25-34** | 中等價值 | 有一定價值但完整度不足；洞察存在但缺乏具體論證 | 深度有限、缺乏論證、資訊密度低 |
| **10-24** | 低價值 | 短片段（<100字）；僅媒體或連結；純推廣無內容 | 資訊密度低、僅有空泛形容詞 |
| **0-9**  | 無價值 | 重複推文；心靈雞湯式發言；純連結無脈絡 | 無實質內容、重複貼文、純連結 |

## 閥門說明

- **寫入閥門：score >= 35**（HARD RULE）
- score < 35 的推文一律不寫入 vault，直接略過
- 門檻理由：35 分代表推文具有實質工作流、洞察或可重用內容

## Why It Matters 模板（依分數區間）

| 分數區間 | 繁中模板 |
|----------|---------|

| 40-44 | 可重用提示詞/技術模式；多步驟工作流+具體工具 |

| 25-34 | 請參考 Reference 原文 |

## 常見評語範例（繁中，40 字以內）

### 45-50 分
- 「提出新概念並附檢驗標準與政治警示，論述結構完整。」
- 「翻譯 Satya Nadella『Token 資本』長文，概念原創且具策略深度。」
- 「揭露 GLM API 隱形計費陷阱，極具實戰警示價值。」
- 「提供完整提示詞工程範本與 Skills 開發流程，極高實戰價值。」

### 40-44 分
- 「提出 .md 檔案應由 Harness 路由而非直接灌入 context 的關鍵認知。」
- 「整理 Lovable 七條團隊觀察，附加公司成長數據，論點有支撐。」
- 「引用推文深度剖析企業AI依賴風險，結論簡潔有力。」

### 35-39 分
- 「提供可複製的 AI 圖像生成公式與 prompt，實用性高但深度有限。」
- 「完整廣告系統框架，四款產品統一視覺語言，有商業應用價值。」

### 25-34 分
- 「觀點簡短有力但缺乏具體論證，資訊密度低。」
- 「提供電影海報風格範例，但實際提示詞在留言區。」

### 0-24 分
- 「僅一則連結，無任何文字脈絡與資訊內容。」
- 「與前一則推文內容完全重複，無新增資訊價值。」
- 「純推廣語無實質內容，無法獨立評價。」

## 評分決策樹

```
推文內容評估
├─ [是否提出原創概念/方法論？]
│   └─ 是 → 40-50 分（取決於完整度）
├─ [是否有完整可複製的工作流/提示詞？]
│   └─ 是 + 具體 → 40-50 分
│   └─ 是 + 不完整 → 35-39 分
├─ [是否有具體數據/金額/案例支撐？]
│   └─ 是 → 40-50 分
├─ [內容是否實質（>200字有意義內容）？]
│   └─ 是 → 35-39 分
│   └─ 否 → 10-34 分
└─ [是否為純連結/媒體/重複/心靈雞湯？]
    └─ 是 → 0-24 分
```

## 硬性排除（直接 0-24 分）

- 純連結分享，無任何內文
- 完全重複的推文（同一內容第三次以上貼出）
- 僅有「行銷/推廣」目的，無實質知識內容
- 短於 50 字的碎念/心情分享
- 只有「值得關注」「很棒」「厲害」等空泛形容詞

# To Outline

## Description

把已經對齊好的 brief 轉成真正可寫的結構，不只是列標題，而是安排每一段要完成的任務。

## Workflow

1. 先讀 brief，確認：
   - 題目
   - 讀者
   - 目的
   - 深度
   - 來源邊界
2. 定義文章骨架：
   - 開頭要做什麼
   - 中段要如何展開
   - 結尾要留下什麼
3. 為每個 section 補三個欄位：
   - 這段的功能
   - 這段的主要內容
   - 需要放的證據或例子
4. 如果是論文或長篇小說，補上層級：
   - 論文：章節、子章節
   - 長篇：卷、arc、章
5. 最後做一次順序檢查，確保論證或敘事能往前推。

## Guardrails

- 不要只列漂亮標題，卻沒有內容任務。
- 不要讓相鄰章節做重複工作。
- 如果大綱太胖，先拆成 v1 與延伸版。

## Output

輸出帶有段落任務與證據位置的大綱，可直接交給 draft 類 skill。

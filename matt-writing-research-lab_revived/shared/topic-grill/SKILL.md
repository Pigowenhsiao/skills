# Topic Grill

## Description

先把寫作題目問清楚，再開始寫。這顆 skill 的工作不是產文，而是把模糊需求變成可執行 brief。

## Workflow

1. 先確認任務類型：
   - 文章
   - 論文摘要
   - 長篇小說
   - 簡報／報告
2. 問清楚六個核心欄位：
   - 主題是什麼
   - 目標讀者是誰
   - 這篇要完成什麼目的
   - 語氣與風格是什麼
   - 篇幅與深度到哪裡
   - 最終交付格式是什麼
3. 如果題目太大，主動收斂成較小的第一版。
4. 產出一份簡短 brief，包含：
   - 核心題目
   - 讀者
   - 目的
   - 範圍邊界
   - 成品格式

## Guardrails

- 不要一邊問一邊偷偷開始寫正文。
- 不要接受「都可以」這類空答案；要逼出實際選擇。
- 如果使用者沒有決定，就給建議答案與理由。

## Output

輸出一份可直接交給 `to-outline` 或其他寫作 skill 的 brief。

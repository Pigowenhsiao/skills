# Sanity Checks

## Common decomposition styles

### population x rate

Example:

- total households
- adoption rate
- purchase frequency

### capacity model

Example:

- total demand
- service capacity per provider

### stock and flow

Example:

- installed base
- replacement cycle

### revenue breakdown

Example:

- customers
- transactions per period
- average ticket

## Assumption sources

Prefer to label assumptions as:

- experience-based
- literature-based
- conservative neutral estimate

## Validation questions

- Is the order of magnitude plausible?
- Does it violate an obvious physical or demographic bound?
- Does it roughly match at least one external benchmark?
- Which assumption dominates the uncertainty?

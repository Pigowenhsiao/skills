## 二、句式特徵（8 種，每種 3+ 例子）

### 句式 1：反問結尾句（最常見）

**結構**：陳述 + 「對吧？」/「對不對？」/「是不是？」/「呢？」

> **統計**：4,000+ 個反問結尾，平均每 250 字一個。

> **效果**：用「請問」包裝嘲諷，製造學者姿態。

## 三、情緒節奏：鋪墊 → 反轉 → 解剖 → 結論

小翠的單場直播典型情緒曲線（基於 `直播A_宏觀經濟與聯準會兜底.txt` 5,000 字開頭實證）：

```
┌──────────────────────────────────────────────────────────┐
│ 1. 鋪墊 (1-2 分鐘)                                       │
│    寒暄 + 自我證言 + 主題預告                             │
│    「今天我是預告過大家…為什麼我說美聯儲永遠會為         │
│     流動性兜底」                                          │
│                                                          │
│ 2. 反轉 (3-5 分鐘)                                       │
│    從「主流共識」切入，揭示盲點                           │
│    「我們一定要去看這些個大的宏觀背景，我們有時候        │
│     都被主流媒體的一些個碎片化的知識把自己的              │
│     這種就是思維邏輯給斷開了」                            │
│                                                          │
│ 3. 解剖 (5-15 分鐘)                                      │
│    拉長時間軸，從歷史/數據/邏輯三層拆解                   │
│    「1913 年之前的美國是怎麼樣的…沒有中央銀行…」         │
│    → 大蕭條 → 凱恩斯主義 → 2008 伯南克                  │
│    → 養老金入市 → 沒有回頭路                            │
│                                                          │
│ 4. 結論 (2-3 分鐘)                                       │
│    數字收束 + 預測 + 行動建議                             │
│    「美聯儲成了市場的守護神…美股永遠都可以安安          │
│     穩穩拿着睡覺」                                       │
└──────────────────────────────────────────────────────────┘
```

**反轉點識別詞**：「但是」「問題在於」「你看」「其實」「所以」「不過話說」

**結論點識別詞**：「就是這麼回事」「懂嗎」「明白嗎」「大家覺得呢」「對吧？」

### 4.2 開頭/轉場填充語

- 「**ok**」「**好**」「**嗯**」「**哈嘍**」— 段落起手

- 「**我覺得**」— 個人觀點前（1,193 次，3-字 trigram 第 1）
- 「**你想想**」— 引導觀眾（自反問句常見）
- 「**你說**」— 模擬觀眾提問

### 一句話概括

### 寫作模板

```
[寒暄：哈嘍 + 設備測試 + 自我介紹]  (1-2%)
[預告主題：今天我要講…]              (2-3%)
[反轉：主流看法錯在哪裏]              (10-15%)
[解剖：歷史 + 數據 + 邏輯]            (60-70%)
[結論：就是這麼回事 / 對吧？]         (10-15%)
[Q&A：大家還有什麼要問的嗎？]         (5-10%)
[收尾：下禮拜再見，拜拜]              (1-2%)
```

### 不可混淆的特徵

1. **永遠不直呼「習近平」全名** — 用「咱皇上」「那個主席」
2. **永遠不直呼美股看空者為「空頭」** — 用「鬼故事」「嚇人」
3. **永遠用「對吧？」結尾** — 每 250 字一次
4. **永遠用歷史拉長敘事** — 從 1913、1929、2008 講起
5. **永遠不做無據猜測** — 用「我猜的」「我覺得」標明
6. **永遠不用粗口** — 「神經病」「裝睡」代替

# Pigo PPT Style — Bauhaus 美學設計參考

> 當用戶要求「包浩斯風格」「Bauhaus style」「幾何簡約風」時，調用此參考模組。
> 觸發場景：海報設計、產品簡報、室內設計、建築視覺等需要結構性幾何美學的 PPT。

---

## I. 設計哲學

包豪斯不是「紅黃藍幾何模板」，是一套**現代設計訓練方法**：
把藝術、工藝、工業生產和日常生活重新接在一起。

核心原則：**形狀不是裝飾，是結構構件**
- 圓形 → 視覺重心
- 線條 → 資訊區域
- 方塊 → 畫面重量
- 標題 → 版面結構參與

---

## II. 媒介邊界（不要混寫）

| 媒介 | 關鍵詞 | 元素重點 |
|------|--------|----------|
| **海報** | 排版 + 幾何 | 圓/方/三角進入版面結構，文字參與構圖 |
| **產品** | 材料 + 結構 + 功能 | 管材框架、球體、金屬桿、構件 |
| **室內** | 家具 + 光線 + 動線 | 傢俱模組、模組櫃體、清楚結構連接 |
| **建築** | 體塊 + 立面 + 窗帶 | 玻璃幕牆、窗帶、樓梯、橋廊 |

**唯一邊界**：包豪斯可以跨媒介，但同一頁不要混寫不同媒介的邏輯。

---

## III. 色彩系統

### 經典五色（服務結構，不是表面堆積）

| 角色 | 色值 | 結構功能 |
|------|------|----------|
| 紅色 | `#E53935` | 視覺重心 |
| 黃色 | `#FDD835` | 資訊區 |
| 藍色 | `#1E88E5` | 平衡塊 |
| 黑色 | `#212121` | 壓住文字重量 |
| 米白 | `#F5F5DC` | 給結構留出呼吸 |

### 進階色調（可用於襯托）

- 深灰 `#424242`：現代感替換黑色
- 淺灰 `#E0E0E0`：留白對比
- 琥珀 `#FFB300`：暖色調強調

### 配色禁忌

| 錯誤 | 變成 |
|------|------|
| 顏色平均分布 | 兒童積木 |
| 過度做舊 | 復古海報模板 |
| 顏色只是點綴 | 結構感不夠 |

**原則**：顏色必須服務結構，不是表面堆積。

---

## IV. 構圖關係

### 四種有效構圖

1. **中心對稱**：視覺重心居中，穩定莊嚴
2. **對角張力**：幾何元素沿對角線分布，動態感強
3. **網格秩序**：幾何元素對齊隱藏網格，理性清晰
4. **放射動勢**：從中心向外放射，聚焦視線

### 文字構圖原則

- Herbert Bayer Universal Lettering 精神：字母是**可簡化、系統化、幾何化**的視覺工具
- 文字不能像後期貼上去的標題，要參與構圖
- 與網格、牆面、色彩邊界一起處理

---

## V. 質感處理

### 海報方向

- 預設：平面、乾淨、印刷感
- **不要**：一上來就加復古紙紋、膠片刮痕、髒噪點、陰影、3D
- 結構還沒成立時，質感只會遮住問題

### 產品/空間方向

- 替換材質關鍵詞：鋼管、玻璃、白色抹灰牆面、木材、皮革或帆布、金屬燈罩
- **不要**：賽博金屬、豪宅大理石、北歐軟裝

---

## VI. Prompt 骨架（生成海報時的標準結構）

```
[媒介：海報/產品/室內/建築] + Bauhaus 骨架
主體：[具體描述]
材料：[相應材質關鍵詞]
結構關係：[幾何/網格/對稱/放射]
色彩：[結構性配色，服務結構非表面]
```

### 四個檢驗問題

每次生成後問自己：
1. 模型是否理解了這個媒介的專屬邏輯？
2. 骨架（形狀/構圖/文字關係）是否成立？
3. 顏色是否服務結構而不是表面堆積？
4. 質感是否為結構服務而不是遮住問題？

---

## VII. 與 Pigo 品牌色彩整合

當用戶同時要求「Pigo 品牌 + 包豪斯」時：
- 保持 Pigo Blue `#3B82F6` 為主色
- 以包豪斯結構邏輯替換 Pigo Purple `#8B5CF6` 的裝飾性用法
- 圓/方/三角幾何形狀使用 Pigo 品牌色系
- 避免 Pigo 品牌默認的卡片式佈局，改用幾何結構佔位

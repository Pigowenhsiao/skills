# Yao GEO Expert Skill

## What It Does

`yao-geo-expert-skill` owns one recurring job:

> Turn an unknown industry or topic request into a structured, explainable, verifiable, and transferable industry expert report. It helps users quickly build cognitive models for a new field, analyze industry boundaries, unpack value chains, identify key variables, and generate industry learning packages and self-testing tutorials.

## How To Use

1. Load the routing and workflow from `SKILL.md`.
2. Input the target industry or topic (e.g., GEO / geometric learning applications, Web3 finance, low-altitude economy).
3. The agent will execute Phase 1 (Input & Analysis) to draft boundaries, classifications, value chains, core players, policies, and risks.
4. The agent will execute Phase 2 (Report Integration) to structure a full report including value-chain mapping, competitive landscape, industry lifecycle, entry barriers, quick learning cards, expert learning path, and Feynman self-test questions.

# learning-recap-to-x

把「看過的好內容」轉化為「可複盤、可輸出」的完整複習包。

## 適用情境

- 使用者說「幫我複盤這段影片/文字稿」並附上連結或文字內容
- 適用於：YouTube 影片、部落格文章、課程逐字稿、推文串、PDF、任何文字素材

## 產出規格

一次輸出五項產物：

1. **骨架筆記** — 5 句話提煉原文主線
2. **有感點清單** — 3 個「我學到了什麼」（不是課程講了什麼）
3. **短推草稿** — 3–5 條，每條一個獨立判斷，可直接發布
4. **配圖建議** — 視覺呈現方式與風格指引
5. **行動清單** — 「之後我會怎麼用」

---

## 流程

### Step 1：抓取素材

- 若為 URL，用 `baoyu-url-to-markdown` 或 `baoyu-youtube-transcript` 抓取正文/字幕
- 若為純文字，直接使用
- 擷取完成後，確實讀過一遍再進入下一步

### Step 2：三層處理法

#### 第一層：原文主線（5 句話骨架）

用5 句話說明這篇內容在說什麼，**不是複述原文，而是提煉骨架**。

範例格式：
-這篇文章在說……
- 核心論點是……
- 關鍵洞見是……
- 這個說法挑戰了……
- 對我最有用的部分是……

**原則**：每句都是一個關鍵判斷，不是描述性語句。

#### 第二層：我的反應（3 個有感點）

找出3 個「我學到了什麼」，**不是「課程講了什麼」**。

對每個有感點追問：
- 為什麼這點讓我有感？
- 我原本的認知是什麼？
- 這個認知現在要怎麼更新？

**原則**：有感點必須是「個人化的」，不是通用總結。

#### 第三層：可輸出觀點（3–5 條短推）

把「我的反應」改寫成判斷句，格式：

```
「我原來以為 A，這次學到 B，關鍵的是 C，以後我會 D」
```

或更簡單的：

```
「今天學到一個很實用的判斷」→ 一句反差觀點 → 展開 2–4 行 → 收束成行動或金句
```

**核心公式**：
```
「我原來以為 A，這次學到 B，關鍵的是 C，以後我會 D」
```

**每一條推文必須有一個獨立判斷**。讀者不需要知道原文，單看這條推文就應該能理解你想說什麼。

### Step 3：人工把關（必要步驟）

AI 生成草稿後，**必須逐條檢查**：

- [ ] 知識點優先級是否正確（最重要的有沒有被稀釋）
- [ ] 語氣是否像 Pigo 說的話（刪掉不像自己說的話）
- [ ] 有沒有未經確認的資訊（數據、引用、聲明），有的話標注「待確認」
- [ ] 內部課程細節是否已移除或模糊化
- [ ] 配圖風格是否與帳號調性一致

**把關後的版本才是最終交付。**

### Step 4：配圖建議

針對每條短推給出：
- 視覺類型（圖卡、流程圖、截圖、梗圖）
- 建議配色或風格關鍵字
-文字量（適合長文圖卡 or短句大字報）

---

## 約束（鐵律）

1. **短推要有個人味道**：不是課程搬運，是 Pigo 的解讀
2. **每條推文必須有一個獨立判斷**：讀者單看這條就知道你想說什麼
3. **刪掉不像我說的話**：行銷腔、通用廢話、未經確認的資訊果斷刪
4. **全程繁體中文輸出**：不用轉換簡體，保留原文語境
5. **人工把關不可跳過**：草稿出來後必須逐條檢查

# 短推發布前檢查清單

每次短推草稿出來後，逐條勾選。**全部 ✅ 才能發布。**

---

## 知識點優先級
- [ ] 最重要的觀點有被強調，不是被稀釋
- [ ] 沒有把核心資訊埋在後面
- [ ] 數據或引用有標注來源

## 語氣像 Pigo
- [ ] 沒有營銷腔（「震撼！」「必看！」「這招太強了！」）
- [ ] 沒有通用廢話（每句話都在說事情，不是湊字數）
- [ ] 沒有彆扭的機器感句子
- [ ] Pigo 真的會這樣說嗎？（大聲朗讀一遍確認）

## 未經確認的資訊
- [ ] 數據有來源嗎？
- [ ] 引用是原文嗎？
- [ ] 聲明是可以公開說的嗎？
- [ ] 有的話標注「❓待確認」

## 內部課程細節
- [ ] 沒有提到具體學員案例或名字
- [ ]沒有引用付費內容的具體操作步驟
- [ ] 沒有暴露課程內部機制

## 配圖風格
- [ ] 視覺類型合適（圖卡/大字報/梗圖/截圖）
- [ ] 配色與帳號調性一致
- [ ] 文字量適合該視覺類型
- [ ] 沒有低級錯誤（錯字、語句不通）

---

## 快速決策捷徑

問題：「這條推文，讀者不需要知道原文，單看這條就應該能理解我想說什麼」嗎？

如果回答不出「我想說什麼」，這條推文就還沒準備好。

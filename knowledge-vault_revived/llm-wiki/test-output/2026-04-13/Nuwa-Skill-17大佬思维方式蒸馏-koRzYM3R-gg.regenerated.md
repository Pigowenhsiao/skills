# Nuwa Skill 蒸餾 17 位大佬思維方式

## 核心摘要

這支影片的核心主張是：真正值得蒸餾成 AI skill 的，不是某個人的說話口氣，而是他在不同情境下反覆展現出來的思考框架、判斷啟發式與知識壓縮方式。換句話說，Nuwa Skill 想做的不是角色扮演，而是抽取「可操作的認知系統」。

影片也同時提出一套蒸餾方法論：透過多來源採集、跨場景驗證、以及一致性測試，把某個人的思維方式轉成可複用的 skill。這讓 skill 從「模仿語氣」提升到「代理思考框架」。

## 文章分析

### 核心論點

影片先對「同事.skill」這種工作習慣蒸餾做延伸，指出如果只是抽取流程習慣，能學到的是做事方式；但若要蒸餾像芒格、費曼、Naval、馬斯克這類人物，真正有價值的是他們如何看世界、如何做判斷、如何定義問題。

因此影片把蒸餾內容拆成五層：心智模型、決策啟發式、表達 DNA、知識事實庫，以及誠實邊界。這個拆法很重要，因為它明確區分了「可以抽取的穩定結構」與「無法被可靠複製的直覺與創造力」。

方法上，影片用六路來源採集加三重驗證，避免只從單一著作或名言抽樣造成失真。只有那些具有生成力、排他性、並跨時間反覆出現的觀點，才值得被認定為某人的核心思維模型。

### 風險與限制

- 這份重產稿依據現有筆記內容整理，不是完整原始影片逐字稿重建。
- 影片本身帶有強烈方法論宣告色彩，因此若要實際驗證 Nuwa Skill 的可靠性，還需要讀對應 repo 與 sample skill。
- 「蒸餾思維」很容易被誇大成「複製大師」，但影片其實已經誠實承認直覺與創造力無法完整蒸餾，這點不能在整理時被省略。

## 關鍵知識點

- Skill 的高階版本，不是模仿語氣，而是抽取認知操作系統。
- 可被蒸餾的內容，至少包括心智模型、決策規則與表達方式。
- 六路採集可以降低單一資料源偏差，三重驗證則提高抽取穩定性。
- 蒸餾後的 skill 應該自帶誠實邊界，明講哪些能力做不到。
- 一致性測試是 skill 質量控制的重要一環，不應只做「看起來像」的表面模仿。

## 全文（繁中重寫）

這支影片的切入點很直接：如果你都想蒸餾一個 skill 了，為什麼只蒸餾身邊同事的工作習慣，而不去蒸餾那些真正留下大量高密度思維材料的大佬？

影片提出的 Nuwa Skill，不是要讓 AI 假裝成某個人說話，而是把一個人的思考結構提煉成可運行的 skill。這裡的差別很大。角色扮演通常只能模仿表面語氣，但如果抽出的是心智模型與決策規則，那麼 skill 在面對新問題時，才有可能表現出接近原人物的分析路徑。

為了做到這件事，影片把可蒸餾內容分成五個層次。第一層是心智模型，也就是一個人如何理解世界。第二層是決策啟發式，也就是在壓力下做判斷時依賴的快速規則。第三層是表達 DNA，重點不是語氣模仿，而是為什麼他偏好用那種方式組織觀點。第四層是知識事實庫，提供可查詢的內容基礎。最後一層是誠實邊界，明確承認哪些東西無法可靠蒸餾，例如直覺、創造跳躍與未曾表達過的內在判斷。

影片的方法論同樣值得注意。它不是只讀一本書或幾段語錄，而是用六條管道去採集資料：著作、訪談、碎片表達、外部視角、決策紀錄、人生時間線。接著再做三重驗證，只保留那些能跨場景生成新判斷、不是所有聰明人都會說、而且在不同時間點反覆出現的觀點。最後再用公開問題與未知問題測一致性，檢查 skill 到底是在模仿文字，還是在複用思考框架。

影片最後最誠實的地方，是它沒有把這件事吹成魔法。它明講蒸餾不等於複製一個人的全部能力。真正高價值的直覺與創造跳躍，不可能只靠文字材料完整重建。這個邊界說明，反而讓整套方法更可信。
